# Security Policy

Thank you for helping keep LX Obsidian Labs projects and their users secure.

## Reporting a vulnerability

**Do not publish exploit details, credentials or sensitive user information in a public GitHub issue.**

Please report security concerns privately to **vilanenathan@gmail.com**, with the subject `Security report — LX Obsidian Labs`.

Where possible, include:
- The affected repository and version or commit
- A concise description of the vulnerability and its potential impact
- Reproduction steps or a safe proof of concept
- Any suggested mitigation

Do not access other people's data, disrupt services, or perform destructive testing.

## Scope and support

This repository serves as an engineering profile. Security support and patch commitments vary by project; check each project's own documentation. No specific response time or remediation SLA is promised here.

Please allow maintainers an opportunity to investigate before public disclosure. We will coordinate disclosure where appropriate.

## Credentials

Never include passwords, tokens, private keys, or real customer data in reports, issues, or pull requests.
